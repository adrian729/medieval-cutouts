# Retained source images

`creature-in-gold-shape.png` is the supplied original, preserved byte for byte so its cutout can be corrected again. It includes the surrounding paper and is reference material, not a reusable transparent asset. Its historical provenance and license have not been established.

The corrected extraction keeps the large pale curved body inside the gold form opaque; the previous extraction incorrectly removed it. The built-in imagegen method can reinterpret fine details and is not a pixel-exact mask. Its exact correction prompt is recorded in `../EXTRACTION-PROMPTS.json`. The reusable PNG/WebP master is capped at the supplied image's 650px longest edge.
